# 촉각 알림 이중과업 실험 웹앱

보고서의 S0/S1/W0/W1 절차에 맞춘 모바일 웹앱입니다. Android Chrome에서 실행하며, 브라우저의 진동 API로 P1/P2를 제시하고 블루투스 2버튼 리모컨 키 입력과 박자음 시각을 저장합니다. 설치 가능한 웹앱(PWA)이며 Android 네이티브 APK는 아닙니다.

## Android에서 여는 방법

1. 저장소의 GitHub Pages를 HTTPS로 활성화합니다. GitHub 저장소의 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`, `main`, `/(root)`를 선택합니다.
2. 배포가 완료되면 Android Chrome에서 `https://unavailableisavailable.github.io/humanfactors/`를 엽니다. GitHub Pages가 활성화되기 전에는 이 주소가 열리지 않을 수 있습니다.
3. Chrome 메뉴에서 **홈 화면에 추가**를 선택하면 앱처럼 실행할 수 있습니다. 첫 실행은 온라인으로 접속해 파일을 캐시합니다.
4. Android에서 화면 자동 꺼짐을 늘리고, 방해 금지/절전 설정이 진동이나 백그라운드 동작을 막지 않는지 확인합니다. 앱은 Screen Wake Lock을 요청하지만 OS가 거부할 수 있습니다.
5. 화면 밝기를 낮추고, 스마트폰 진동과 이어폰 출력을 확인합니다. 리모컨 버튼 A/B를 각 한 번 눌러 앱에 키를 지정합니다. 두 버튼의 키 코드가 서로 다르고 시행 중 브라우저에 전달되는지 파일럿으로 확인하세요.

## 한 참가자 진행

1. 참가자 ID, Williams 순서, 버튼 대응을 설정하고 진동·박자음·잡음·리모컨을 점검합니다.
2. 동의를 확인합니다. 음성 녹음은 별도 동의가 있을 때만 선택합니다. 카메라 영상은 별도 장비로 기록합니다.
3. 걷기와 계산 단독 기준선을 각각 2분 수행하고, 보행·계산 결과를 기록지에 적습니다.
4. 네 조건을 지정 순서로 진행합니다. 조건마다 24회, 8회씩 3개 소블록이며 각 소블록은 P1/P2 각 4회입니다. 소블록 사이 피로도를 입력하고 최소 30초 쉽니다. 조건 종료 뒤 Raw NASA-TLX를 입력하고 최소 1분 쉽니다.
5. 계산 조건은 다음 단계로 넘어가기 전에 앱이 표시하는 시작 숫자를 참가자에게 알려줍니다. 계산 답변을 말하는 시점은 팀에서 파일럿 전에 한 가지 규칙으로 정해 모든 참가자에게 동일하게 안내해야 합니다.
6. 완료 또는 중단 화면에서 시행 CSV와 세션 JSON을 다운로드합니다. 음성 녹음에 동의한 경우 음성 파일도 별도로 내려받습니다. 내려받은 자료를 확인한 뒤 연구팀의 접근 제한 저장 위치로 옮깁니다.

## 시행 동작과 로그

- P1: 200–400–200ms 진동 펄스, P2: 200–200–400ms 펄스. 펄스 사이 간격은 각각 150ms입니다.
- 박자음은 3초 간격입니다. 시행마다 2박 또는 3박을 건너뛰고, 해당 박자음 뒤 1,300–1,800ms에 진동 명령을 보냅니다.
- 8회 소블록 안에서 P1/P2를 4회씩 무작위 순서로 제시합니다. 응답 제한시간은 명령 호출 뒤 4.5초이며 첫 입력만 기록합니다.
- 550ms 미만 입력은 예측 입력으로 표시합니다. 저장된 RT는 물리적 진동 시작이 아니라 브라우저의 진동 명령 호출부터 버튼 이벤트까지의 시간입니다.
- 시행 중 화면이 백그라운드로 가면 앱은 해당 세션을 중단 상태로 기록합니다. 안전 담당자는 참가자를 먼저 안전하게 정지시킨 뒤 기기를 꺼내 화면을 세 번 눌러 중단할 수 있습니다.

## 자료 및 한계

참가자 ID, 시행 로그, 기준선 입력, 피로도, NASA-TLX는 해당 브라우저의 `localStorage`에 저장됩니다. CSV는 시행 단위 자료, JSON은 전체 세션 자료입니다. 음성 파일은 브라우저에서 별도로 녹음·다운로드합니다. 자료는 자동으로 서버에 전송되지 않습니다.

진동 API의 성공 반환은 실제 모터 작동 시각이나 강도를 확인하지 않습니다. 호출 시각·응답 시각 차이는 웹앱 수준의 값이므로 물리적인 촉각 자극 시작 기준 RT로 해석하면 안 됩니다. 실험 시작 전 같은 Android 기기·브라우저·리모컨 조합으로 충분히 파일럿을 진행하세요. 이어폰 잡음은 주변 지시와 보행 안전을 해치지 않는 가장 낮은 수준으로 설정합니다.

## 파일

- `index.html`: 설정, 사전 점검, 기준선 타이머, 진동 시행, 휴식·피로도·NASA-TLX, 내보내기
- `manifest.webmanifest`, `icon.svg`: 홈 화면 설치 정보와 앱 아이콘
- `sw.js`: 오프라인 캐시
